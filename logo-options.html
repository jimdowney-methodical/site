Methodical Security — Logo Options

Five directions, all built as inline SVG so they scale crisply at any size and recolor with CSS variables. Each option is shown at large display size, in a header lockup on light and dark backgrounds, and in the existing nav-bar context for direct comparison with the current "M-in-square" mark.

Option 1
Layered Shield

Three nested shields — outer navy, middle blue, inner cyan — visualizing defense-in-depth and the methodical layering of controls. The classic shield silhouette reads instantly as "security" and signals defense-industry seriousness without resorting to literal padlocks.

Option 2
Grid Matrix M

An "M" formed from a 5×5 grid of squares — filled cells make the letterform, empty cells are outlined. Reads as "methodical" through visible structure and as "controls" through the grid metaphor (think SPRS scoring, control families, OSCAL data). The center square uses the cyan accent so the eye lands on the heart of the M.

Option 5
Hex Compliance Mark

A blue hexagonal frame with an "M" centered inside, and six small cyan dots at each vertex representing checkpoints / control families. Hex + Shield Variations

Combining Hex Frame with Layered Shield

Three takes on a hex-as-certification-frame around the layered-shield mark. The hex now reads as the compliance/certification boundary and the shield carries the security meaning, which gives the lockup more semantic weight than hex+letterform alone — and pulls it away from the HashiCorp / Vault visual territory.

Variation 5A
Hex Frame + Layered Shield

Direct combination: a clean blue hex outline with the three-layer shield from Option 1 nested inside. The hex is the "certified" wrapper; the shield-in-shield-in-shield is "defense in depth." Most literal of the three variations.
